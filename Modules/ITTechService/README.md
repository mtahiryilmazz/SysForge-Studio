# Project VANGUARD IT 🛰️

**Project VANGUARD IT (Sentinel IT Technical Service Management)**, kurumsal düzeyde Bilgi İşlem teknik servis süreçlerini yönetmek, envanter takibi yapmak ve ağ yönetimini kolaylaştırmak için geliştirilmiş modüler bir yazılımdır.

## 🚀 Öne Çıkan Özellikler

- **Gelişmiş Dashboard**: Anlık istatistikler ve bekleyen arıza kayıtları.
- **Arıza Kayıt Sistemi**: Bölüm ve personel bazlı detaylı ticket yönetimi.
- **Akıllı Donanım Envanteri**: Cihaz özellikleri, garanti durumu ve zimmet takibi.
- **Gelişmiş Ağ Tarayıcı**: Windows, Mac, Linux ve ağ cihazlarını otomatik algılayan ikonik haritalama.
- **Web İzleme Paneli (Flask)**: Admin ve personel için merkezi web erişimi.
- **Uzaktan Kontrol (AnyDesk Stili)**: Modern üst bara sahip canlı ekran izleme, klavye/fare kontrolü ve sistem makroları.
- **Otomatik Ekran Arşivi**: Her anlık ekran kaydını tarih ve cihaz bazlı yerel diske kaydetme.

## 🛠️ Teknoloji Yığını

- **Frontend**: PySide6 (Qt for Python)
- **Backend**: Python 3.x, Flask (Web Portalı)
- **Veritabanı**: SQLite3
- **Stil**: Modern Dark/Light Tema Desteği (Custom QSS)

## 📦 Kurulum

1. Depoyu klonlayın:
   ```bash
   git clone https://github.com/KULLANICI_ADINIZ/it-tech-service.git
   ```
2. Bağımlılıkları yükleyin:
   ```bash
   pip install -r requirements.txt
   ```
3. Uygulamayı başlatın:
   ```bash
   python VanguardIT.py
   ```
